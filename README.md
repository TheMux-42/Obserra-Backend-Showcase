# Obserra-Backend-Showcase

Showcase vom **Obserra.net Discord Bot Backend** – ohne Source-Code-Leaks.

Dieses Repository ist bewusst als **Demo- und Dokumentations-Repo** aufgebaut:
- nur Erklärungen
- nur Bilder/Screenshots
- keine produktiven C#-Implementierungsdetails

## Ziel

Mit diesem Repo kannst du zeigen, dass dein Backend funktioniert, ohne internen Code öffentlich zu machen.

## Struktur

```text
Obserra-Backend-Showcase/
├── README.md
├── docs/
│   ├── 01-projektueberblick.md
│   ├── 02-architektur-ohne-code.md
│   └── 03-funktionsnachweise.md
└── assets/
    └── images/
        ├── README.md
        └── .gitkeep
```

## Nächste Schritte

1. `docs/01-projektueberblick.md` mit Zweck, Features und Tech-Stack ausfüllen.
2. `docs/02-architektur-ohne-code.md` mit Architektur-Erklärung ohne Code füllen.
3. `docs/03-funktionsnachweise.md` mit Screenshots/Beweisen ergänzen.
4. Bilder in `assets/images/` ablegen und in den Docs verlinken.

## Sicherheit

Vor dem Hochladen von Screenshots immer prüfen:
- keine Tokens, Secrets oder API-Keys sichtbar
- keine privaten URLs, IDs oder internen Hostnamen sichtbar
- sensible User-Daten unkenntlich machen
